# AI Creator — демо-версия бесплатного урока «Создай своего AI-героя»

React + TypeScript + Tailwind + Framer Motion. Без бэкенда, без внешних API, без сбора персональных данных.

```bash
npm install
npm run dev              # http://localhost:5173
npm run build
npm run test:scenarios   # прогон сценариев диалога в консоли
```

## Что где
- `src/lib/nlu.ts` — разбор слов ребёнка: тип героя (в т. ч. люди, английские слова), цвета, детали, одежда, стиль, имя, бессмыслица, личные данные.
- `src/lib/dialog.ts` — сценарий наставника: вопросы (максимум 4), правки «было → стало», имя героя, итоги урока.
- `src/lib/art/*` — демо-иллюстрации (дракон, робот, воин, зверь, дух).
- `src/lib/imageProvider.ts` — **точка подключения настоящей генерации**: реализуйте `HeroImageProvider`.
- `src/config/offer.ts` — **цена и условия программы**, `enrollUrl` (ссылка на запись), текст «что ещё не утверждено».
- `src/lib/analytics.ts` — события воронки без внешних сервисов (`aiCreatorStats()` в консоли, `setSink()` для подключения своей системы).
- `src/hooks/useChat.ts` — лента, этапы (`creating_character` … `parent_offer`), localStorage (`aicreator.chat.v2`).

## Что остаётся демонстрацией
Наставник работает по сценарию; картинки — готовые иллюстрации, подстроенные по цвету и ряду деталей. Генерация по произвольному запросу, видео, запись и оплата не подключены.

## Реальная генерация картинок (fal.ai)

Ключ хранится только на сервере и в браузер не попадает. Без ключа приложение работает в демо-режиме.

1. Скопируйте `.env.example` в `.env.local` (он уже создан) и впишите ключ одной строкой: `FAL_KEY=ваш_ключ` (без кавычек и пробелов).
2. Перезапустите `npm run dev`. В консоли появится `[fal] генерация включена`.
3. Модели: `fal-ai/nano-banana` (создание) и `fal-ai/nano-banana/edit` (правки с прошлой версией героя). Цена на страницах моделей fal.ai: $0.039 за изображение.
4. Лимиты (меняются в `.env.local`): 4 картинки на урок, 8 запросов в час с адреса, 100 картинок в день; `FAL_ENABLED=false` отключает генерацию.
5. `FAL_MOCK=1` — тестовый режим: интерфейс работает как с ИИ, но ответы имитируются и расходов нет.

Проверка без расходов: `npm run test:server`.

Серверный код: `server/` (проверка текста, сбор промпта, лимиты, обработчик `/api/status` и `/api/generate`); подключается к dev- и preview-серверу Vite. Для публикации потребуется Node-хостинг, где этот обработчик запускается как сервер.

## Публикация с реальной генерацией (Render)

GitHub Pages отдаёт только статические файлы, поэтому там работает демо. Для реальной генерации нужен постоянно работающий Node-сервер. В репозитории есть `server/index.ts` (отдаёт приложение и API) и `render.yaml` для Render:

1. Render → New → Blueprint → выбрать репозиторий. Ключ `FAL_KEY` и код доступа `FAL_ACCESS_CODE` ввести в панели Render (не в репозиторий).
2. Ссылка для людей: `https://ВАШ-САЙТ.onrender.com/?code=КОД_ДОСТУПА`. Без кода открывается демо-режим с готовыми картинками.
3. Локальная проверка боевого режима: `npm run build && npm run build:server && FAL_MOCK=1 npm start`.
4. Реальный предел расходов задаёт баланс (и лимиты расходов) в кабинете fal.ai: счётчики сервера хранятся в памяти и сбрасываются при перезапуске.

## Публикация на Vercel (функции + общий Redis для лимитов)

Vercel Hobby разрешён только для некоммерческого личного использования (Fair Use Guidelines). Для теста подходит; для коммерческого запуска нужен план Pro либо другой хостинг, код от этого не зависит.

- `api/generate.js` и `api/status.js` — собранные (esbuild) серверные функции; пересборка: `npm run build:api` (Vercel делает это сам перед сборкой сайта).
- Лимиты хранятся в Upstash Redis (атомарный Lua-скрипт): дневной, общий, на урок, на адрес в час, одновременные запросы. Без Redis генерация выключена (демо-режим), а не «без контроля».
- Защита: проверка слов на сервере, один запрос не обрабатывается дважды (`x-request-id`), прошлые картинки героя принимаются только с подписью сервера, адреса и номера уроков в Redis лежат хэшами.
- Переменные окружения Vercel: `FAL_KEY` (секретная), `FAL_DAILY_LIMIT`, `FAL_TOTAL_LIMIT`, `FAL_SESSION_LIMIT`, `FAL_HOURLY_PER_IP`; Redis добавляется из Vercel Marketplace (Upstash for Redis, Free).
- Тесты без сети и расходов: `npm run test:server` (в том числе Lua-скрипты на настоящей Lua-машине).
