# Запуск AI Creator в интернете с настоящей генерацией (Vercel + Upstash + fal.ai)

Время: около 20 минут. Нужны: аккаунт GitHub (уже есть), ключ fal.ai (уже есть), почта для Vercel и Upstash.

## 0. Что получится
Ссылка вида `https://ai-creator-demo-xxxx.vercel.app`, которую можно отправлять кому угодно. Люди проходят урок сами и получают картинку через fal.ai. Расходы ограничены лимитами (ниже).

## 1. Vercel: создать проект
1. Откройте https://vercel.com/signup → **Continue with GitHub** → разрешите доступ. Тариф **Hobby**.
2. **Add New… → Project** → найдите репозиторий **ai-creator-demo** → **Import**.
   (Если репозитория нет в списке: «Adjust GitHub App Permissions» → выберите репозиторий → Save.)
3. Framework Preset должен определиться как **Vite**. Настройки сборки не меняйте.

## 2. Vercel: переменные окружения (до первого Deploy)
Раскройте **Environment Variables** и добавьте строки «Name → Value» (Environment: все три галочки):

| Name | Value | Примечание |
|---|---|---|
| `FAL_KEY` | ваш ключ fal.ai | включите **Sensitive** |
| `FAL_TOTAL_LIMIT` | `50` | всего картинок за всё время (≈ $2) |
| `FAL_DAILY_LIMIT` | `20` | картинок в день |
| `FAL_SESSION_LIMIT` | `4` | картинок на один урок |
| `FAL_HOURLY_PER_IP` | `6` | запросов в час с одного адреса |

Нажмите **Deploy**. Через 1–2 минуты появится адрес сайта.

## 3. Upstash Redis: хранилище лимитов (бесплатно)
Без него генерация сама выключается (так задумано).
1. В проекте на Vercel откройте вкладку **Storage**.
2. **Create Database** (или **Marketplace**) → **Upstash** → **Redis** → план **Free** → имя `ai-creator-limits` → регион ближе к вам (например, Frankfurt) → **Create**.
3. **Connect Project** → выберите ваш проект, окружения: Production, Preview, Development. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.

## 4. Перезапуск и проверка
1. **Deployments** → у последнего деплоя меню «⋯» → **Redeploy**.
2. Откройте `https://ВАШ-САЙТ.vercel.app/api/status`. Должно быть `"enabled":true`. Если `false`: Redis не подключён (шаг 3) или не выполнен Redeploy.
3. Если сайт просит войти в Vercel: **Settings → Deployment Protection** → отключите **Vercel Authentication** для Production.

## 5. fal.ai: ограничить расходы
В кабинете fal.ai пополните баланс на небольшую сумму ($5–10) и не включайте автопополнение. Это настоящий предел расходов.

## 6. Первая проверка
Откройте сайт, пройдите урок. Над картинкой должна быть метка **«Создано ИИ»** (не «Демо-изображение»). Одна генерация ≈ $0.039.

## Как управлять
- **Выключить генерацию:** Vercel → Settings → Environment Variables → `FAL_ENABLED` = `false` → Redeploy (сайт останется, будет демо-режим).
- **Поднять или снизить лимиты:** изменить переменные из шага 2 → Redeploy.
- **Сколько использовано:** Upstash → вашу базу → Data Browser: ключи `fal:total` (всего) и `fal:day:ДАТА`. Обнулить счётчик: удалить ключ.
- **Обновить сайт после правок кода:** изменения попадают на GitHub (ветка main), Vercel собирает сайт сам.

## Важно знать
- **Vercel Hobby — только для некоммерческого использования** (в том числе нельзя рекламировать продажу услуги). В приложении показана цена 4 900 ₽, поэтому для настоящих продаж нужен тариф Vercel Pro или другой хостинг; код от этого не зависит.
- Описание героя (без личных данных) отправляется на сервер Vercel и затем в fal.ai (США). Для публичного запуска детям нужна политика конфиденциальности и юридическая оценка.
